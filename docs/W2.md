# W2 Notes

This iteration adds the backend foundation for fast manual execution.

## Done

- `POST /api/v1/orders/floating` for fast floating-price limit orders.
- Floating price calculation uses Binance `bookTicker` bid/ask, not TradingView.
- Price rounding follows order side: BUY rounds down, SELL rounds up.
- Ladder orders are independent and each gets its own `fl-` client order id.
- `POST /api/v1/orders/close-all` cancels open orders per active symbol and market-closes positions.
- `POST /api/v1/orders/reverse` cancels current symbol orders, closes the current position, then opens the same size opposite direction.
- Tests cover floating basis price, ladder calculation, hard guard behavior, auth, and quick-action side mapping.
