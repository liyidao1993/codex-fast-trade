## 判定

当前 502 不是前端代理问题。后端已经收到请求并调用 Binance，失败点在 Binance 签名接口认证。`-2015` 通常对应以下之一：

- API Key 不是当前 Futures Demo/Testnet 环境生成的 Key。
- Key 权限未启用 Futures/API trading。
- Key 配了 IP 白名单，但后端 Python 出网 IP 不在白名单。
- Key/Secret 输入不匹配或复制错误。
