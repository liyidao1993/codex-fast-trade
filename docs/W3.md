# W3 Notes

This iteration adds the backend core for protection orders, chase decisions, and reconciliation planning.

## Done

- `ProtectionOrder` model and parent order TP/SL fields.
- `trading/protection.py` calculates and submits `STOP_MARKET` and `TAKE_PROFIT_MARKET` reduce-only protection orders.
- Manual endpoint `POST /api/v1/orders/{client_order_id}/protection` for attaching TP/SL after a known fill.
- `trading/chase.py` contains the deterministic chase decision state core.
- `trading/reconcile.py` classifies local active orders vs exchange open orders.
- Tests cover long/short protection price math, chase decisions, and reconciliation classification.
